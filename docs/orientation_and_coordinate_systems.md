# 双 IMU 姿态解算、坐标系与关节角定义

> 对应软件版本：Knee_joint 1.1.0；AHRS 0.4.0。本文记录当前程序的实际实现，
> 可作为论文“方法”章节、参数表和实验复现记录的基础。最终投稿时仍应以实际实验配置为准。

## 1. 系统范围

系统使用固定在相邻肢段上的两枚 WT901 IMU：近端传感器 S_p 和远端传感器 S_d。
每对同步样本同时进入 Mahony 非线性互补滤波器和四元数扩展卡尔曼滤波器（EKF），
分别产生一套传感器姿态、相对姿态和三轴相对角。

当前两条链路均为 6 轴融合，只使用加速度计和陀螺仪。原始数据中的 Geo_x/y/z，
以及设备固件输出的 Angle_x/y/z，均不参与姿态解算。

## 2. 坐标系定义

| 符号 | 名称 | 当前实现中的定义 |
|---|---|---|
| S_p | 近端传感器坐标系 | WT901 原始 Acc/Gyr 的 X、Y、Z 轴；程序不交换轴，也不翻转符号 |
| S_d | 远端传感器坐标系 | 定义同上 |
| N | 局部导航坐标系 | 重力对齐的右手坐标系；EKF 采用 AHRS 的 NED 形式 |
| J | 零位补偿相对姿态 | 近端到远端的相对姿态相对于静态标定零位的变化；它不是额外的物理传感器坐标系 |

安装约定为：两枚传感器的 X 轴分别沿对应骨段指向远端关节，例如大腿 X 轴指向膝，
小腿 X 轴指向踝；Y、Z 轴依照外壳标记组成右手系。标定姿势下，两传感器坐标系应尽量
平行。当前软件不会自动辨识传感器到骨段的固定安装旋转，也不会估计解剖轴。

### 2.1 NED 的严格含义

AHRS EKF 配置项 frame=NED 规定数学模型中的参考重力方向采用 NED 形式，即
X、Y、Z 分别按 North、East、Down 的右手坐标约定构造。

但是，本项目没有使用磁力计或其他绝对航向观测。重力只能约束倾斜方向，不能确定
绕重力轴的航向。因此：

- N 系的 Z 轴由静止重力观测对齐；
- 初始化时把 yaw 设为 0；
- 水平面内的 X、Y 方向只是局部初始方向，不代表经过测量确认的地理北和地理东；
- 论文中建议写“采用 NED 形式的重力对齐局部导航坐标系”，不要直接写“地理 NED 坐标系”。

Mahony 链路使用同一类重力对齐初始化和加速度观测，因此也具有相同的航向不可观限制。

## 3. 四元数方向与运算约定

程序统一采用 Hamilton 四元数乘法和标量在前顺序：

    q = [q_w, q_x, q_y, q_z]^T
    ||q||₂ = 1

记 q_(N←S) 为“传感器坐标系 S 相对于导航坐标系 N 的姿态”。它把在 S 系表示的
向量旋转到 N 系：

    v_N = q_(N←S) ⊗ [0, v_S] ⊗ q_(N←S)*

其中 ⊗ 表示 Hamilton 四元数乘法，* 表示共轭。单位四元数满足 q⁻¹=q*。
AHRS 0.4.0 的滤波器输出以及本项目 quaternion.py 均采用 [w, x, y, z] 顺序。

四元数 q 与 −q 描述同一旋转。标定阶段对四元数求平均前会先做半球对齐，以避免
同一姿态的正负表示互相抵消。

## 4. 输入、单位和时序

每枚传感器的原始输入向量可写为：

    u = [a_x, a_y, a_z, ω_x, ω_y, ω_z, m_x, m_y, m_z]

当前处理规则如下：

| 项目 | 原始单位 | 滤波器单位 | 处理 |
|---|---:|---:|---|
| 加速度 a | g | m/s² | 乘以 g₀=9.80665 m/s²；滤波观测中再归一化为方向 |
| 角速度 ω | deg/s | rad/s | 乘以 π/180 |
| 磁场 Geo_* | 设备原始单位 | 未使用 | use_mag=False |
| 设备角度 Angle_* | deg | 未使用 | 不混入设备固件内部的未知滤波结果 |

默认采样频率 f_s=100 Hz，滤波器固定使用：

    Δt = 1/f_s = 0.01 s

esp32_rx_ms 用于双传感器帧匹配和输出时间轴，但当前没有把逐帧实测时间差作为滤波器的
可变 Δt。论文复现时必须报告配置的 f_s，并注明滤波器采用固定采样周期。

进入姿态引擎前，加速度模长必须满足 0.3g ≤ ||a|| ≤ 3.5g。两路数据依据
esp32_rx_ms 做一对一近邻匹配，默认允许的最大时间差为 30 ms。

## 5. Mahony 姿态解算

### 5.1 模型

程序调用 AHRS 0.4.0 的 Mahony.updateIMU。该算法是在 SO(3) 上定义的显式非线性
互补滤波器；当前仅利用归一化加速度给出的重力方向修正陀螺积分。

与本实现对应的核心关系可概括为：

    ω_mes = a_unit × a_hat
    b_hat_dot = −k_I · ω_mes
    ω_corr = ω_meas − b_hat + k_P · ω_mes
    q_hat_dot = 0.5 · q_hat ⊗ [0, ω_corr]
    q_t = normalize(q_(t−1) + q_hat_dot · Δt)

其中 a_unit 是归一化加速度方向，a_hat 是当前姿态预测的重力观测方向，
ω_mes 是由重力方向差得到的姿态误差，b_hat 是在线估计的陀螺零偏。
k_P 控制即时姿态修正强度，k_I 控制偏置积分估计速度。

### 5.2 当前参数

| 参数 | 当前值 | 定义 |
|---|---:|---|
| frequency | 100 Hz，取配置 fs | 固定更新频率 |
| use_mag | False | 仅使用加速度计和陀螺仪 |
| k_P | 0.5 | 姿态误差比例反馈增益 |
| k_I | 0.1 | 陀螺零偏积分反馈增益 |
| acc_unit | g | 输入后乘 9.80665 |
| gyr_unit | deg/s | 输入后转换为 rad/s |

k_P=0.5、k_I=0.1 是本项目参数，而非 AHRS 类的默认参数。AHRS 0.4.0 文档所列
默认值为 k_P=1.0、k_I=0.3。

### 5.3 初始化和偏置处理

实时引擎先收集 200 对有效同步帧。每枚传感器的初始姿态由静止窗口平均加速度计算：
roll 和 pitch 由重力方向确定，yaw 初始化为 0。静止窗口的平均角速度作为初始陀螺
零偏写入 Mahony 内部状态 b，随后由 k_I 在线更新。

## 6. 四元数 EKF 姿态解算

### 6.1 状态与预测

程序使用 AHRS 0.4.0 的四元数 EKF。状态只包含单位四元数，不包含陀螺零偏：

    x_t = q_t = [q_w, q_x, q_y, q_z]^T
    P_t ∈ R^(4×4)

陀螺读数作为控制输入，以一阶离散模型预测姿态：

    q_pred = [I₄ + (Δt/2)Ω(ω_t)] q_(t−1)
    P_pred = F_t P_(t−1) F_t^T + var_gyr · W_t W_t^T

### 6.2 加速度观测与校正

当前 6 轴模式只使用归一化加速度方向作为观测：

    z_t = a_t / ||a_t||
    z_pred = C(q_pred)^T [0, 0, 1]^T
    R = var_acc · I₃

标准 EKF 校正为：

    K_t = P_pred H_t^T [H_t P_pred H_t^T + R]⁻¹
    q_t = normalize(q_pred + K_t[z_t − z_pred])
    P_t = [I₄ − K_t H_t] P_pred

这里 C(q) 是由四元数得到的方向余弦矩阵，H_t 是重力观测模型相对于四元数状态的
雅可比矩阵。

### 6.3 当前参数及含义

| 参数 | 当前值 | 定义 |
|---|---:|---|
| frame | NED | 全局参考方向采用 NED 形式；不等于已经获得地理航向 |
| frequency | 100 Hz，取配置 fs | 固定 Δt=1/f_s |
| use_mag | False | 观测维数为 3，只使用加速度方向 |
| var_gyr | 0.09=0.3² | 各向同性陀螺过程噪声方差 |
| var_acc | 0.25=0.5² | 归一化加速度观测的各向同性噪声方差，R=0.25I₃ |
| var_mag | 0.64=0.8² | 参数已初始化，但当前 6 轴更新不使用 |
| P₀ | I₄ | 初始四元数状态协方差 |

var_gyr 和 var_acc 可在 config.json 中设置，也可由命令行参数
--kalman-var-gyr、--kalman-var-acc 覆盖。参数越大表示相应来源越不可信：

- 增大 var_acc 会减弱加速度观测对姿态的校正；
- 增大 var_gyr 会提高预测不确定性，使校正阶段相对更依赖观测；
- 论文中应报告实际值及其确定方法，不能只写“使用卡尔曼滤波”。

上述数值目前采用 AHRS 0.4.0 EKF 文档的默认噪声设置，尚未依据 WT901 的静态噪声、
Allan 方差或实验协方差重新辨识。

### 6.4 初始化和偏置处理

EKF 使用与 Mahony 相同的 200 帧平均加速度初始化 q₀，yaw 置零，P₀=I₄。
由于 AHRS 的该 EKF 状态不含陀螺偏置，本项目计算静止窗口平均角速度 ω_bar，并在每次
EKF 更新前固定扣除：

    ω_corr,t = ω_raw,t − ω_bar

这与 Mahony 的在线偏置估计不同。若单帧 EKF 更新产生非有限四元数或协方差求解异常，
程序保留上一帧姿态，并把 P 重置为 I₄。

## 7. 相对姿态和零位标定

下列运算对 Mahony 与 EKF 分别独立执行。对任一算法 A，近端和远端姿态分别为
q_(N←S_p,t)^A 和 q_(N←S_d,t)^A。当前相对姿态定义为：

    q_rel,t^A = [q_(N←S_p,t)^A]⁻¹ ⊗ q_(N←S_d,t)^A

它描述远端传感器相对于近端传感器的旋转。

站立标定窗口默认 3 s，即在 100 Hz 下为 300 帧。对同一算法的姿态序列先做半球对齐：
若 q_i·q_ref<0，则用 −q_i 替代 q_i；随后计算归一化算术平均：

    q_bar = normalize[(1/n) Σ q_i_aligned]

这是半球对齐后的归一化算术平均，不是 Markley 特征值四元数平均。每种算法的标定零位为：

    q_rel,0^A = [q_bar_(N←S_p)^A]⁻¹ ⊗ q_bar_(N←S_d)^A

零位补偿相对旋转为：

    q_joint,t^A = [q_rel,0^A]⁻¹ ⊗ q_rel,t^A

所以在理想标定姿势下，q_joint=[1,0,0,0]^T，三个输出角均为 0。

标定文件中：

- q_rel_0 保存 Mahony 零位；
- q_rel_0_kalman 保存 EKF 零位；
- 旧标定文件缺少 EKF 字段时，程序会为了兼容临时复用 Mahony 零位；
- 正式实验应重新标定，生成两套独立零位。

静态标定的接受条件是两枚传感器均满足：

- 陀螺模长的窗口标准差小于 10 deg/s；
- 加速度模长的窗口标准差小于 0.15 g。

## 8. 欧拉角顺序、输出映射与符号

单位四元数采用 Z-Y-X Tait–Bryan 分解：

    R = R_z(yaw) R_y(pitch) R_x(roll)

它也可等价表述为绕随体 X-Y-Z 轴依次进行的内禀旋转。代码公式为：

    roll  = atan2[2(q_w q_x + q_y q_z), 1 − 2(q_x² + q_y²)]
    pitch = asin [2(q_w q_y − q_z q_x)]
    yaw   = atan2[2(q_w q_z + q_x q_y), 1 − 2(q_y² + q_z²)]

工程输出映射如下：

| 输出字段 | 欧拉分量 | 当前约定的含义 | 正方向 |
|---|---|---|---|
| flexion_deg / kalman_flexion_deg | roll，绕 X | 屈曲/伸展 | 屈曲为正，伸展为负 |
| abduction_deg / kalman_abduction_deg | pitch，绕 Y | 外展/内收 | 外展为正，内收为负 |
| rotation_deg / kalman_rotation_deg | yaw，绕 Z | 外旋/内旋 | 外旋为正，内旋为负 |

角度单位为 degree。roll、yaw 的主值范围约为 [−180°, 180°]，pitch 范围为
[−90°, 90°]；pitch 接近 ±90° 时存在欧拉角奇异性。

### 8.1 论文表述边界

当前输出应准确称为“零位补偿后的双传感器相对 Z-Y-X 欧拉角”。程序尚未实现：

- ISB 推荐的解剖学关节坐标系；
- 基于解剖标志或规定动作的功能轴标定；
- 传感器到骨段坐标系固定旋转的单独估计。

因此，在完成额外的解剖学或功能标定验证之前，不应把这三个输出直接称为严格的临床
骨段角或 ISB 关节角。安装误差、软组织伪影和欧拉角串扰均可能影响结果。

## 9. Mahony 与 EKF 的可比性

两种算法共享同一对同步原始帧、单位转换、200 帧初始静止窗口、固定采样频率，
以及相同的相对四元数、零位补偿和欧拉角计算函数。

| 项目 | Mahony | 四元数 EKF |
|---|---|---|
| 估计形式 | 确定性误差反馈 | 随机状态估计与协方差传播 |
| 状态 | 姿态四元数和内部偏置估计 | 姿态四元数；P 为 4×4 协方差 |
| 陀螺偏置 | 初始化后在线更新 | 初始化估计后固定扣除 |
| 加速度权重 | 由 k_P、k_I 调节 | 由 var_gyr、var_acc 和 P 调节 |
| 绝对航向 | 无 | 无 |

两条链路都没有磁力计，因此 yaw 或轴向旋转缺少绝对航向观测，可能随陀螺偏置漂移。
近端与远端的共同漂移可能在相对姿态中部分抵消，但不能保证完全消除。

## 10. 可用于论文的方法描述

以下段落可作为初稿，投稿前应按最终实验配置修改参数并补充安装细节：

> 两枚三轴惯性传感器分别固定于相邻肢段。加速度与角速度数据以 100 Hz 采集，并依据
> ESP32 接收时间戳进行一对一近邻同步，允许的最大时间差为 30 ms。原始加速度由 g 转换为
> m/s²，角速度由 deg/s 转换为 rad/s。同步数据分别输入 Mahony 非线性互补滤波器
>（k_P=0.5，k_I=0.1）和标量在前的四元数扩展卡尔曼滤波器。EKF 状态为单位四元数，
> 初始协方差为 I₄，陀螺过程噪声方差与加速度观测噪声方差分别设置为 0.09 和 0.25。
> 两种算法均只融合加速度计与陀螺仪，不使用磁力计。每枚传感器利用 200 帧静止数据
> 初始化 roll、pitch 和陀螺零偏，yaw 初值设为零。站立零位标定中，分别计算近端和远端
> 姿态四元数的半球对齐归一化均值，并为两种算法独立定义初始相对姿态。时刻 t 的关节
> 相对姿态按 q_joint,t=q_rel,0⁻¹⊗(q_prox,t⁻¹⊗q_dist,t) 计算，随后采用 Z-Y-X
> Tait–Bryan 分解得到 roll、pitch 和 yaw，并按传感器安装约定分别报告为屈伸、外展和
> 轴向旋转角。由于未使用磁力计，水平航向不可观，轴向旋转角可能发生漂移。

## 11. 实验复现清单

建议每次正式实验归档：

1. 软件版本、AHRS 版本和最终 config.json。
2. 近端/远端传感器序列号及设备别名映射。
3. 每枚传感器 X/Y/Z 轴相对人体前、外侧和远端方向的照片或文字说明。
4. 实际采样率、同步容差、丢帧数和同步时间差统计。
5. 标定姿势、标定时长、静止判定阈值，以及两套 q_rel,0。
6. Mahony 的 k_P、k_I，以及 EKF 的 var_gyr、var_acc、P₀。
7. 是否使用磁力计；若未来启用，应记录硬铁/软铁标定和当地磁场参考。
8. 与光学动作捕捉、测角仪或其他参考系统的同步与验证方法。

## 12. 当前限制

- 6 轴姿态不能由重力观测独立确定 yaw，轴向旋转可能漂移。
- 固定 Δt 假定有效采样周期稳定；时间戳只参与配对和绘图。
- 快速运动中的线性加速度会污染重力观测，使两种滤波器产生瞬态姿态误差。
- EKF 噪声目前是各向同性经验值，尚未根据具体 WT901 数据辨识。
- 传感器到骨段的固定旋转尚未通过解剖或功能标定单独估计。
- Z-Y-X 欧拉角存在顺序依赖、串扰和 pitch 接近 ±90° 时的奇异性。
- 软组织伪影不在算法模型中。
